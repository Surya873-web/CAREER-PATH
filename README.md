# CareerPath AI

CareerPath AI helps you explore career options with a short interest assessment, personalized career matches, and a practical learning roadmap.

## Live website

https://careerpath-ai-t4vf.onrender.com/

## Features

- Five-question interactive career assessment
- Career matches with fit scores and explanations
- Roadmaps with learning milestones and project ideas
- Responsive layout with subtle 3D visual effects
- No account or sign-up required

## Run locally

Open `index.html` in a browser, or serve this directory with a local web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

The site is hosted on Render as a static site connected to the `main` branch of this repository. Render serves the repository root (`.`) without a build command and automatically redeploys when changes are pushed.
